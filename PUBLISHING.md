# Public GitHub preparation

1. Confirm rights to publish the original code and choose a license. For MIT,
   add its standard license text with the owner's copyright name.
2. Create an empty public repository, for example `hubble-scout`.
3. Upload this folder's contents, excluding .venv, caches and personal workspaces.
   Alternatively initialize Git here, commit, add your remote and push.
4. Enable Actions, inspect the Windows tests and enable private security reports.
5. Add a screenshot using synthetic data and attach a source ZIP to a release.

Suggested topics: astronomy, hubble, fits, astropy, computer-vision,
distributed-computing. Source distribution requires Python; there is no signed
standalone executable. No GitHub upload has been performed by this preparation.
